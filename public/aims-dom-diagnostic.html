AIMS DOM Diagnostic

Targeted crew-structure diagnostic. Version 5.

Set up once
  1. Tap Copy AIMS DOM Diagnostic.
  2. Create or update the browser bookmark named eScrew DOM Diagnostic.
  3. Replace its URL with the copied code.
Run where crew names are visible
  1. Open AIMS and show the flight/details screen with crew names.
  2. Run eScrew DOM Diagnostic.
  3. Paste the copied JSON into ChatGPT.

The output contains only DOM structure and pattern flags around crew candidates. It never emits visible text, names, staff IDs, form values, credentials, cookies, tokens, URLs, request bodies or session data.
