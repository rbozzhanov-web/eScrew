AIMS DOM Diagnostic

Desktop-only diagnostic for locating crew data already rendered by AIMS.

Set up once
  1. Tap Copy AIMS DOM Diagnostic.
  2. Create a browser bookmark named eScrew DOM Diagnostic.
  3. Edit the bookmark and replace its URL with the copied code.
Run on desktop AIMS
  1. Open AIMS and navigate to the flight/details screen where crew names are visibly shown.
  2. Run eScrew DOM Diagnostic.
  3. The diagnostic is copied to your clipboard. Paste that JSON into ChatGPT.

The output contains only DOM structure, counts and pattern flags. It never emits visible text, crew names, staff IDs, form values, credentials, cookies, tokens, URLs, request bodies or session data.
