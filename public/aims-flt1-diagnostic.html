AIMS FLT1 Diagnostic

Fresh diagnostic based on the CrewSchedule page source. It watches only the flight-detail response used by AIMS itself.

Set up once
  1. Press Copy FLT1 Diagnostic.
  2. Create a bookmark named eScrew FLT1 Diagnostic.
  3. Replace the bookmark URL with the copied code.
Run in AIMS
  1. Open Crew Schedule.
  2. Run eScrew FLT1 Diagnostic.
  3. Open a flight and open its FLT1 / flight-detail window.
  4. When the floating box says captured, press Copy diagnostic.

No names, staff IDs, response text, form values, credentials, cookies, tokens, request bodies or session data are emitted. The request is not replayed.
