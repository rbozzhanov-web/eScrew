What to Do If You See 404 Errors

  1. Check Authentication - Make sure you're logged in to AIMS
  2. Check URL Structure - Verify the path is correct (case-sensitive)
  3. Try Alternative Endpoint - If Dashboard fails, try SchedulerEvents
  4. Report Issue - Share the results with support including:
    • Your AIMS URL
    • Which endpoint failed (404)
    • Response headers and status
    • Browser console errors
