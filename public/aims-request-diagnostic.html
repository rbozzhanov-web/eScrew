AIMS Request Diagnostic

Finds the real Air Astana roster request without exposing credentials or session data.

Set up
  1. Tap Copy diagnostic bookmark.
  2. Create a Safari bookmark named eScrew Request Diagnostic.
  3. Edit the bookmark URL and paste the copied code.
Run in AIMS
  1. Open AIMS and go to My Schedule.
  2. Run eScrew Request Diagnostic.
  3. When the overlay says it is listening, change the displayed roster period once or use a My Schedule control that reloads the roster.
  4. When the roster response is found, tap Copy diagnostic and send the text back here.

The diagnostic stores only request method, same-origin path and request-body field names. It never stores passwords, cookies, auth headers, tokens, CSRF/session values, or request-body values.
