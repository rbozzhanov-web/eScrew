AIMS Request Diagnostic

Finds the roster POST shape without exporting request values or session data.

Set up
  1. Tap Copy diagnostic bookmark.
  2. Replace the URL of your eScrew Request Diagnostic Safari bookmark.
Run in AIMS
  1. Open My Schedule.
  2. Run the diagnostic bookmark.
  3. Change the displayed roster period once.
  4. Tap Copy diagnostic and send the JSON back here.

Output contains method, pathname, outer body keys and a value-free structural description of the Data field. No raw Data value, cookies, auth headers, tokens, CSRF/session values, passwords or query values are copied.
