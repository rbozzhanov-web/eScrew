eScrew Capture

Одноразовая настройка. После неё обычный путь будет коротким и всегда начинается из eScrew.

Ежедневный сценарий

eScrew → AIMS → Поделиться → eScrew Capture → eScrew

Без Web Archive, Save to Files и повторного выбора файла. Данные возвращаются в eScrew через URL fragment и не отправляются на GitHub Pages сервер.

Настройка Shortcut

1

Создай новую быструю команду и назови её eScrew Capture.

2

В деталях включи Показывать на странице экспорта / Show in Share Sheet и оставь входной тип Safari webpages.

3

Добавь действие Run JavaScript on Web Page / Выполнить JavaScript на веб‑странице и вставь код ниже.

4

Добавь следом действие Open URLs / Открыть URL. В качестве URL выбери результат предыдущего JavaScript‑действия.

5

Готово. В eScrew нажимаешь AIMS, ждёшь Crew Schedule, затем Поделиться → eScrew Capture.

JavaScript для Shortcut

Скрипт берёт только ростер, crew/member tree, hotel и hours. Cookies, session, auth headers, CSRF, passwords, request Data и токены он не читает.
