Обновление транспорта Shortcut. v4 возвращает ростер через URL-safe base64 с проверкой длины, чтобы Safari/Shortcuts не повреждали JSON.

Замени только JavaScript внутри существующего действия Run JavaScript on Web Page. Остальные шаги Shortcut не меняются.
