eScrew AIMS Capture

PWA-only setup. No extra app or Safari extension is required.

Set up once
  1. Tap Copy AIMS Capture.
  2. In Safari create a bookmark named eScrew Capture.
  3. Edit that bookmark and replace its URL with the copied Capture code.
Normal use
  1. In eScrew tap AIMS.
  2. Safari opens AIMS. Sign in if needed.
  3. Run the eScrew Capture bookmark once.
  4. Capture arms itself and opens My Schedule automatically.
  5. When ready, tap Copy roster to eScrew.
  6. Return to eScrew and tap AIMS again to paste/import.

No manual My Schedule navigation, Period change, Zoom change, userscript manager, or Safari extension is required.
