eScrew AIMS Connector

One-time Safari setup. The connector runs only inside aims.airastana.com, observes the normal AIMS schedule request, and copies only roster JSON for eScrew.

iPhone / iPad
  1. Add this page to Safari bookmarks.
  2. Edit that bookmark and replace its URL with the connector copied below.
  3. Open AIMS in normal Safari and sign in.
  4. On Crew Schedule, run the “eScrew AIMS” bookmark.
  5. If the schedule is already visible, change Zoom (for example Week → Month → Week) or the Period so AIMS refreshes it.
  6. Tap “Copy roster to eScrew” after the status changes to roster captured, return to eScrew, then tap AIMS.
Privacy boundary

The connector never asks for or reads your password. It does not serialize cookies, CSRF values, tokens, request bodies, or the short Retrieve response. Authentication stays entirely inside Safari; only the sanitized roster payload is copied.
