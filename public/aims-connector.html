eScrew AIMS Connector

One-time Safari setup. The connector runs only inside aims.airastana.com, observes the normal AIMS schedule request, and sends only roster JSON to eScrew.

iPhone / iPad
  1. Add this page to Safari bookmarks.
  2. Edit that bookmark and replace its URL with the connector copied below.
  3. From eScrew, open AIMS and sign in normally.
  4. On the Crew Schedule page, run the “eScrew AIMS” bookmark once.
Privacy boundary

The connector never asks for or reads your password. It does not serialize cookies, CSRF values, tokens, or the short Retrieve response. Authentication stays entirely inside the native AIMS browser session.
