eScrew AIMS Connector

One-time Safari setup. Arm the connector on the AIMS home page before opening My Schedule. It observes the normal AIMS schedule request and copies only roster JSON for eScrew.

iPhone / iPad
  1. Add this page to Safari bookmarks.
  2. Edit that bookmark and replace its URL with the connector copied below.
  3. Open AIMS in normal Safari and sign in.
  4. While still on the AIMS home page, run the “eScrew AIMS” bookmark.
  5. After the armed message appears, open My Schedule normally.
  6. When the status changes to “Copy roster to eScrew”, tap it, return to eScrew, then tap AIMS.
Privacy boundary

The connector never asks for or reads your password. It does not serialize cookies, CSRF values, tokens, request bodies, or the short Retrieve response. Authentication stays entirely inside Safari; only the sanitized roster payload is copied.
