Diagnostic import

  1. Open AIMS from eScrew and sign in.
  2. Open My Schedule.
  3. Run the eScrew AIMS bookmark.
  4. After “Listening for roster request…” appears, change the visible roster period once or use any control that reloads My Schedule.
  5. When eScrew recognises the roster response, tap Send to eScrew.

The diagnostic records only request method/path and body field names. It does not read passwords, cookies, auth headers, tokens, or request-body values.
