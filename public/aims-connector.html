eScrew AIMS Connector

Recommended setup: install the persistent connector once in a Safari userscript extension. After that it starts automatically on aims.airastana.com, including after page reloads and navigation.

Persistent setup — recommended
  1. Enable a Safari userscript extension on your iPhone/iPad and allow it on aims.airastana.com.
  2. Open the eScrew persistent connector below and install it in that extension once.
  3. After installation, use AIMS normally: sign in and open My Schedule. eScrew capture starts automatically.
  4. When “Copy roster to eScrew” appears, tap it, return to eScrew, then tap AIMS to import.
Bookmark fallback

Use this only if a Safari userscript extension is not available. The bookmark connector must be started manually for each new Safari page/session.

Privacy boundary

Both connector modes only inspect normal AIMS response bodies for roster-shaped JSON. They do not read or copy passwords, cookies, CSRF values, tokens, request bodies, credentials, or session data.
