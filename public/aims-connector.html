eScrew AIMS Connector

One-time setup for automatic roster import

How it works

This setup creates a bookmarklet that runs inside AIMS. When you tap it, it captures your roster data and sends it directly to eScrew—no credentials or session data required.

Setup (once)

  1. Tap Copy AIMS Connector below.
  2. Open Safari settings → Bookmarks.
  3. Create a new bookmark named eScrew AIMS Connector.
  4. Edit that bookmark and replace its URL with what you copied.

Usage

  1. In eScrew, tap the A button (top-right) to open AIMS.
  2. Sign in to AIMS if needed and navigate to My Schedule.
  3. Run the eScrew AIMS Connector bookmark.
  4. Wait for the popup to show "Waiting for roster data…".
  5. Navigate through your roster in AIMS (scroll, change views, etc.).
  6. When ready, tap "Send to eScrew" in the popup.
  7. Your roster will appear in eScrew automatically.

Privacy

✓ Your AIMS login stays in Safari only
✓ No passwords or session tokens are captured
✓ Only roster schedule data is sent to eScrew
✓ Everything runs locally in your browser
