eScrew AIMS

Secure roster capture from your signed-in AIMS page

Before you start

Sign in to Air Astana AIMS in Safari. eScrew never asks for or stores your AIMS password, cookies, tokens or session data.

One-time setup

1
Copy the Capture bookmark

Tap the button below.

2
Create or update a Safari bookmark

Name it “eScrew Capture” and replace its URL with the copied code.

Each import

  1. Tap the A button in eScrew to open AIMS.
  2. Run the eScrew Capture bookmark in AIMS.
  3. Capture arms itself and tries to activate My Schedule. If AIMS is already showing the roster and no new request fires, change the roster period once.
  4. When Roster ready appears, tap Send to eScrew.

Capture sends the sanitized SchedulerEvents roster response, including hotel and other roster metadata when AIMS provides it. Request bodies, passwords, cookies, headers, tokens and session data are never copied.
