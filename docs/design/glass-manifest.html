Engineering mechanics

The patterns that make the look and the app work, written to be dropped into a fresh React Native / Expo Web project.

Palette as a single memo, threaded by prop

MainScreen.tsx

No theme context, no styled-components. One useMemo keyed on useColorScheme() resolves the whole token object once per render; every component receives it as a plain palette prop. Simple to trace, easy to port.

type Palette = { background:string; surface:string; surfaceStrong:string;
  text:string; muted:string; line:string; accent:string; accentSoft:string;
  gold:string; danger:string; weekend:string };

const dark = hydrated && useColorScheme() === 'dark';
const palette = useMemo(() => dark ? { /* dark tokens */ } : { /* light tokens */ }, [dark]);

Cross-platform glass, without breaking native

MainScreen.tsx

backdrop-filter has no React Native equivalent, so it's injected only on web via Platform.select and cast to any — spread straight into a StyleSheet entry. On iOS/Android the spread is undefined and silently no-ops.

const WEB_GLASS = Platform.OS === 'web'
  ? ({ backdropFilter: 'blur(24px) saturate(1.4)',
       WebkitBackdropFilter: 'blur(24px) saturate(1.4)' } as any)
  : undefined;

depthSurface: {
  shadowColor: '#000', shadowOffset: { width: 0, height: 10 },
  shadowOpacity: .1, shadowRadius: 24, elevation: 5,
  ...WEB_GLASS, // blur only where it can render
}

Sheet & dialog primitives

IOSOverlay.tsx

Two reusable overlay components, <IOSSheet> and <IOSDialog>, built on RN's Modal. Both animate with Animated.spring/Animated.timing and mount/unmount via a small visible → mounted state machine so exit animations complete before unmount. The sheet adds a PanResponder for swipe-to-dismiss, with a webScrollAtTop() helper that inspects the DOM under the gesture to tell "user is scrolling a list" from "user is dragging the sheet" — needed because RN Web's own scroll and gesture systems don't arbitrate that for you.

// gesture only claims the drag if the touched list is already at its scroll top
onMoveShouldSetPanResponder: (_, g) =>
  gestureStartedAtTop.current && g.dy > 4 && Math.abs(g.dy) > Math.abs(g.dx) * 1.15

Local-only storage, explicit backup

storage/backup.ts

All data lives in localStorage, never a server. Export builds a Blob, points an off-screen anchor's download attribute at an object URL, and clicks it programmatically — the same primitive as any browser file download, no server round-trip. Restore reuses expo-document-picker and merges by a natural key (period start) rather than replacing wholesale.

const blob = new Blob([JSON.stringify(backup, null, 2)], { type: 'application/json' });
const href = URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = href; link.download = filename;
document.body.appendChild(link); link.click(); link.remove();
setTimeout(() => URL.revokeObjectURL(href), 1000);

Build-time version stamp

package.json · scripts

EXPO_PUBLIC_* vars are inlined by Metro at bundle time, not read at runtime — so the build script exports a fresh timestamp inline, right before the export command runs, and a plain component reads it off process.env.

"build:web": "EXPO_PUBLIC_ESCREW_BUILT_AT=$(date -u +%Y-%m-%dT%H:%M:%SZ) expo export --platform web --output-dir dist"

Carry-over principles

materialGlass is additive — get the flat palette and layout right first, then add blur/translucency/shadow as one final pass on top. Adding it earlier makes contrast bugs hard to see.
tokensOne palette object, all colors sourced from it. Zero literal hex codes inside component styles — makes a full re-theme a one-file edit.
platformWeb-only CSS (backdrop-filter, calc() heights) goes through Platform.select, cast as any, isolated in one named constant per effect — never inlined ad hoc.
numbersAnything a user reads as a number — times, hours, dates — gets a monospace font and tabular-nums, even inside an otherwise proportional UI.
privacyNo credential, token, or session ever enters app state. Only the business data the user explicitly imports does — and it never leaves the device.
