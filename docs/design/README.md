# eScrew Design Concept (v1)

Reference design system for future UI work. See `design-concept-v1.png`.

## Palette
| Role | Hex |
|---|---|
| Background | `#F6F7FA` |
| Card | `#FFFFFF` |
| Border | `#E9EDF2` |
| Secondary | `#687280` |
| Primary | `#0F172A` |
| Accent | `#2D7DFF` |
| Highlight | `#A58B4F` |

## Typography (SF Pro / iOS system)
| Style | Weight | Size / Line height |
|---|---|---|
| Title / Large | Semibold | 28 / 34 |
| Header | Semibold | 17 / 22 |
| Body | Regular | 15 / 20 |
| Caption | Medium | 13 / 18 |
| Mono / Numbers | SF Mono | 15 / 20 |

## Screens covered in the concept
- Home — Today
- Roster — List
- Flight — Details
- AIMS
- Stats (example)
- Settings

Shared pattern: card-based layout, rounded corners, bottom tab bar
(Home / Calendar / AIMS / Settings), aviation-clean aesthetic.

This is a reference for future refinement passes — not yet applied to the app.
