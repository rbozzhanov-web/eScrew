# Import a saved AIMS Web Archive without touching Files

Normally, importing from AIMS means: Safari → Share → Options → Web Archive →
**Save to Files** → switch to eScrew → pick that file. This Shortcut is a
local bridge that skips the Files trip: it grabs the Web Archive straight
from the Share Sheet, puts it on the device-only clipboard, and eScrew
imports it with one deliberate tap. No file is saved to Files, and no byte
is uploaded anywhere.

This uses the same clipboard-bridge technique as the companion
[OFP Viewer app's Shortcut](https://github.com/rbozzhanov-web/Iphone-OFP-viewer/blob/main/SHORTCUT_IMPORT.md)
— if you've already built that one, this is the same shape with a
different prefix and a bigger payload. It is **not** related to eScrew's
older Shortcut-based capture (removed a while back), which ran live inside
the AIMS Safari tab under a hard execution time limit and broke often as a
result. This one only ever touches a Web Archive file that's already been
generated by Safari — nothing runs against the live page.

## Make the Shortcut once

In **Shortcuts**, create a shortcut named **Import to eScrew**.

1. Open the shortcut's details. Enable **Show in Share Sheet**.
2. Under *Share Sheet Types*, select whichever types include Web Archives on
   your iOS version — usually **Files**, sometimes listed alongside **Web
   Pages**. If Safari's Web Archive share option doesn't offer this Shortcut
   as a destination, try widening the type selection; this step is the one
   most likely to need adjusting by hand once you're in the editor.
3. Add **Base64 Encode**. Feed it the *Shortcut Input* and set *Line Breaks*
   to **None**.
4. Add a **Text** action. Its text must be exactly:
   `ESCREW-WEBARCHIVE-v1:` followed immediately by the magic variable from
   the Base64 action — no spaces and no new line.
5. Add **Copy to Clipboard**. Feed it the Text output and enable **Local
   Only**.
6. Add **Show Notification** with: `Open eScrew, tap AIMS, then Paste Web
   Archive from Shortcut.`

## Use it

1. Open Crew Schedule in AIMS and wait for it to finish loading.
2. **Share → Options → Web Archive**, then tap **Import to eScrew** instead
   of Save to Files.
3. Open eScrew, tap the AIMS entry point, then **Paste Web Archive from
   Shortcut**, and allow paste when iOS asks.

A real AIMS Web Archive runs several megabytes — almost all of it is the
AIMS app's own JS/CSS/fonts, which eScrew's importer ignores entirely; the
Shortcut still has to move the whole file across the clipboard today, since
trimming it down to just the useful ~200KB HTML fragment inside the archive
would need Shortcuts to reach into the file's underlying property-list
structure, which hasn't been worked out yet. If the paste stalls or fails
on a large Web Archive, that's the next thing to build — see eScrew's
`src/import/pickRoster.ts` (`pasteRosterFromClipboard`) for where the
receiving side lives. The normal file picker (**Import Web Archive or
PDF**) remains available and unaffected either way.
