# eScrew

Personal Air Astana crew roster companion.

## Scope

- Schedule / roster only
- Air Astana-inspired color palette
- No salary / payslip features
- No Special / Loved Mode
- Preserve the KhaVair roster experience, layout, interactions, sheets, swipe behavior, PWA/offline support, and roster import logic
